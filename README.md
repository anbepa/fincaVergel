# Sonora Coffee Replica

This is a React reproduction of [sonoracoffee.com](https://www.sonoracoffee.com/).

## Project Structure

- **Landing Page**: The entry point at `/` with a background image slider.
- **Home Dashboard**: Located at `/home`, featuring a grid navigation to various sections.
- **Sections**:
  - The Farm (`/thefarm`) - *Fully implemented with content.*
  - Other sections (`/ourprocess`, `/gettoknowus`, etc.) are scaffolded with routes and placeholder components.
- **Navigation**: Full top navigation and footer.

## Getting Started

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Run Development Server**:
    ```bash
    npm run dev
    ```

3.  **Build for Production**:
    ```bash
    npm run build
    ```

## Notes

- Images are sourced directly from the original Squarespace CDN.
- Fonts are approximated using Google Fonts (Playfair Display for serif, Lato for sans-serif).
- Colors and layout mimic the original minimal "Sonora" style.
